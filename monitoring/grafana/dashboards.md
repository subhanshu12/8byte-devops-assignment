# Grafana Dashboards

## Dashboard 1 — Infrastructure Dashboard

Purpose:
Monitor infrastructure health.

Metrics:
- CPU usage
- Memory usage
- Disk utilization
- Node health

---

## Dashboard 2 — Kubernetes Dashboard

Purpose:
Monitor Kubernetes workloads.

Metrics:
- Pod status
- Deployment replicas
- Namespace usage
- Container restarts

---

## Dashboard 3 — Application Dashboard

Purpose:
Monitor application performance.

Metrics:
- Request rate
- Error rate
- Response latency
- Application uptime

---

## Dashboard 4 — Database Dashboard

Purpose:
Monitor PostgreSQL database.

Metrics:
- Active connections
- Storage utilization
- Query activity
